## Лабораторная работа №1 — Основы 3D-графики

**Вариант 1.** Отрисовка 3D-куба средствами Vulkan API с управлением через библиотеку ImGui.

### Задания

Реализовать отрисовку 3D-куба и предоставить пользователю управление следующими параметрами через ImGui:
1. Переключение перспективной и ортографической проекций.
2. Изменение цвета объекта.
3. Изменение положения объекта по трём осям.
4. Изменение углов поворота по трём осям.
5. Изменение масштаба по трём осям.
6. Автоматическая анимация движения объекта с регулируемой скоростью и радиусом.

### Что реализовано

- [x] Геометрия куба (8 вершин, 36 индексов) в вершинном и индексном буферах VRAM.
- [x] Uniform-буфер с MVP-матрицей и цветом, связанный с шейдером через descriptor set.
- [x] Графический конвейер Vulkan (vertex + fragment шейдеры, тест глубины, отсечение).
- [x] Интерфейс ImGui:
  - `Perspective Projection` — переключение проекций;
  - `Object Color` — цвет куба;
  - `Position X/Y/Z` — положение;
  - `Rotation X/Y/Z` — повороты;
  - `Scale X/Y/Z` — масштаб;
  - `Play Animation`, `Speed`, `Radius` — анимация по траектории Лиссажу.

### Используемые технологии

- **Язык:** C++
- **Графическое API:** Vulkan
- **Библиотеки:** GLFW, VkBootstrap, VMA (Vulkan Memory Allocator), ImGui
- **Сборка:** CMake
- **Компилятор шейдеров:** glslc (Vulkan SDK)

### Сборка и запуск

#### Требования

1. **Vulkan SDK 1.4.321.1** или новее — [скачать](https://sdk.lunarg.com/sdk/download/1.4.321.1/windows/vulkansdk-windows-X64-1.4.321.1.exe)
2. **CMake 3.15+**
3. **Компилятор C++17:** MSVC (Visual Studio 2022) или GCC/Clang

#### Windows (Visual Studio)

1. Открыть папку проекта в Visual Studio: `File → Open → Folder...`
2. Дождаться автоматической генерации CMake-проектов.
3. Выбрать конфигурацию `Debug` и цель `vulkan-starter-app`.
4. `Build → Build All` (Ctrl+Shift+B).
5. `Debug → Start Without Debugging` (Ctrl+F5)
